# DecodeLabs-AI-2026

Projects from the DecodeLabs AI Internship, 2026 cohort.

The idea is to build up in layers - start with plain logic, then work toward the probabilistic, learning-based stuff. Each project lives in its own folder.

## Projects

### Project 1 - Marzon (Rule-Based AI Chatbot)
`/Project-1-Marzon-Rule-based-AI-Chatbot`

A chatbot with no learning involved; just a dictionary and a loop. Terminal version in Python, browser version in HTML/CSS/JS.

Point of the exercise: understand control flow and deterministic logic before touching anything probabilistic.
